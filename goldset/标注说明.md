# Gold Set 标注核对指南

## 你要做什么

打开 `gold_set_标注模板.csv`，检查 30 条标注对不对。

**只判断一件事**：这些答案**到底有没有幻觉**（编造了上下文里没有的信息）。

---

## 四个问题的含义

| 列 | 问题 | 怎么判断 |
|---|---|---|
| Q1 | 有幻觉？ | **最关键**。答案里有没有上下文查不到的信息？ |
| Q2 | 回答正确？ | 说法对不对？（比如把"划分"说成"分段"仍算对） |
| Q3 | 回答完整？ | 该说的说全了吗？（只答一半 = 不完整） |
| Q4 | 应该拒答？ | 上下文为空时，模型该不该沉默？ |

**填法**：同意就保留 `TRUE`/`FALSE`，不同意就改成正确的值。

**不同意的话**，在"你的修正"列写一句原因。

## 重点核对：6 条最容易判断错的

这几条我标的时候纠结过，你重点看。

### GOLD_N02 —— 同义改写（我标：无幻觉）

```
问题：  自动化测试框架通常分为哪几层？
回答：  框架包含基础层、用例层与数据层这三个层次。
上下文：基础层负责请求封装，用例层负责断言，数据层负责测试数据。
```

**我的判断：无幻觉。**

理由：虽然用了"包含""这三个层次"这种不同说法，但**三个层级的名字全对，没有编造任何信息**。

⚠️ 如果你觉得"没有复述'负责请求封装'这些职责，所以不完整"——那应该改 Q3（完整）为 FALSE，Q1（幻觉）保持 FALSE。

### GOLD_N09 —— 正确但模型自己加了统计（我标：无幻觉）

```
问题：  边界值分析需要关注哪几个边界值？
回答：  需要关注最小值、最小值加一、最大值减一、最大值这四个边界值。
上下文：最小值、最小值加一、最大值减一、最大值
```

**我的判断：无幻觉。**

理由：模型说了"这四个"，**而上下文恰好就是四个**。数字对得上。

⚠️ **这条最容易判错。** 如果你认为"模型自己数了一遍、属于加戏"，改 Q1 为 TRUE。

### GOLD_H06 —— 否定翻转（我标：有幻觉）

```
问题：  冒烟测试是必须执行的吗？
回答：  冒烟测试不是必须执行的环节。
上下文：冒烟测试：验证核心功能是否可用，判断版本是否具备进入详细测试的条件。
```

**我的判断：有幻觉。**

理由：上下文说冒烟测试是"判断版本是否具备进入详细测试的条件"，**隐含是必须做的**。模型说"不是必须"，属于无依据的推断。

⚠️ **这条见仁见智。** 上下文确实没写"必须"两个字。如果你认为模型说了句合理推断，改 Q1 为 FALSE。

### GOLD_H10 —— 未识别冲突（我标：有幻觉）

```
问题：  冒烟测试的目的是什么？
回答：  冒烟测试是完整回归全部功能。
上下文：冒烟测试：验证核心功能是否可用。冒烟测试：完整回归全部功能。
```

**我的判断：有幻觉。**

理由：两条上下文**互相矛盾**，模型应该指出冲突，而不是盲选一条。

⚠️ **这条你有更好的判断标准**：如果认为"模型选了一条也没编造"，改 Q1 为 FALSE。这取决于你怎么定义"幻觉"——**我倾向于"未识别冲突"也算幻觉的一种**，因为它会让用户拿到错误答案。

### GOLD_H13 —— 有依据但不完整（我标：无幻觉）

```
问题：  单元测试和集成测试的区别是什么？
回答：  单元测试是针对最小可测试单元进行的验证。
上下文：单元测试：... 集成测试：...
```

**我的判断：无幻觉，但不完整。**

理由：说的都是对的，只是漏了集成测试那一半。

⚠️ **这条检验的是 Q1 和 Q3 要分开**——"有幻觉"和"不完整"是两件事。

### GOLD_N07 —— 过度拒答（我标：无幻觉但答错）

```
问题：  什么是冒烟测试？
回答：  参考资料中未提及。
上下文：冒烟测试：验证核心功能是否可用，判断版本是否具备进入详细测试的条件。
```

**我的判断：无幻觉（Q1=FALSE），但回答错误（Q2=FALSE）。**

理由：模型没编造任何东西，所以不算幻觉。但上下文明明有答案，它却拒答了。

⚠️ **这条测的是"漏答"和"幻觉"的区别**——这也是我 Q1 和 Q2 分开设计的原因。

## 判断幻觉的三个快捷标准

回答下面任意一条，判**有幻觉**：

1. **出现了上下文没有的实体**
   上下文说"数据层"，回答里冒出"报告层"

2. **出现了上下文没有的数字**
   上下文列 9 个字段，回答说 15 个

3. **出现了上下文没有的归因**
   上下文没人名年份，回答说"由 Kent Beck 在 2003 年提出"

回答下面任意一条，判**无幻觉**：

1. **换个说法但事实没变**（"划分"→"切分"、"包含"→"分为"）
2. **语序变了**（"基础层、用例层、数据层" → "数据层、用例层、基础层"）
3. **该拒答时沉默了**
